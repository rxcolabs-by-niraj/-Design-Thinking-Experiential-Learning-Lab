# Design Thinking & Experiential Learning Lab — Dr. Niiraj K. Bafna

Static site for GitHub Pages.

## Deploy
1. In the repo `-Design-Thinking-Experiential-Learning-Lab`, replace the old `index.html` with this one.
2. Upload the whole `assets/` folder (keep the folder structure: `assets/img`, `assets/video`).
3. Commit to the branch GitHub Pages serves (usually `main`). The site updates in ~1 minute.

All videos are self-hosted MP4s (largest is ~17 MB, well under GitHub's 100 MB limit).
The National Youth Day talk (90 min) plays through an embedded Google Drive player, and the two
YouTube talks use YouTube embeds — keep those files shared as "Anyone with the link".
